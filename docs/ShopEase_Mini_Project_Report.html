Abstract

Modern e-commerce applications demand fast user interfaces, trustworthy product metadata, frictionless digital payments, and scalable cloud hosting without heavy server maintenance costs. ShopEase is a full-stack Indian e-commerce platform and multi-vendor marketplace engineered using React 19.3, Tailwind CSS v4, Node.js / Express 5 serverless functions on Vercel and Cloudflare Workers, and a cloud-hosted Supabase PostgreSQL relational database.

Unlike static template stores, ShopEase curates 429 verified real products across 14 categories where every single product image is verified reachable via automated HTTP HEAD checks and paired with interactive retail widgets (multi-angle image gallery, No-Cost EMI estimator, UPI cashback calculator, review split analytics, and pincode ETA verification). Beyond standard buyer checkout via NPCI-validated UPI IDs and Phone OTP verification, ShopEase incorporates two practical monetization pillars: (1) a “Sell on ShopEase” Seller Marketplace charging a transparent ₹20 per active item per day platform fee tracked in a PostgreSQL ledger, and (2) a Partner Store Bridge & External Receipt Sync architecture designed for affiliate revenue with Amazon Associates India and partner webhooks.

1. Introduction

The rapid expansion of Unified Payments Interface (UPI) and affordable mobile internet in India has transformed digital retail. However, building an e-commerce platform that works reliably in real-world conditions requires far more than rendering static product cards. Small developers and student teams face three critical bottlenecks: managing backend infrastructure costs, preventing broken or mismatched product imagery, and establishing a sustainable monetization model.

ShopEase addresses these challenges through a serverless-first architecture. Originally initiated as a college mini-project focused on full-stack cloud hosting, ShopEase matured into a dual-model marketplace combining direct-to-consumer UPI sales, OTP-authenticated local seller onboarding, and an external brand/affiliate website bridge. Every transaction, OTP challenge, UPI VPA, seller listing, and daily fee ledger entry persists in a cloud-managed PostgreSQL database on Supabase, served over HTTPS through Vercel Serverless Functions and an equivalent Cloudflare Workers runtime.

2. Objectives

  • Cloud-Native Serverless Hosting: Deploy a zero-downtime SPA frontend and stateless REST API on Vercel and Cloudflare Workers backed by Supabase PostgreSQL Transaction Pooler.
  • Verified Original Product Catalog: Maintain a large catalog (429+ items across 14 categories) where every item displays its own unique, HTTP-verified product photograph, realistic Indian INR pricing, multi-image gallery, and source website link.
  • Authentic UPI & Phone OTP Verification: Enforce SHA-256 hashed 6-digit phone OTP authentication and NPCI bank handle validation (@okicici, @ybl, @paytm, etc.) before linking UPI accounts or opening seller stores.
  • Sustainable Revenue Architecture: Support direct seller subscriptions at ₹20/item/day paid via Admin UPI QR and affiliate link tracking ready for Amazon Associates India.
  • Unified Order Tracking & Tax Invoices: Provide printable GST-style warranty invoices, partner webhook order forwarding, and external order receipt archiving inside one unified Orders portal.

3. Scope of the System

The scope of ShopEase spans customer discovery, marketplace onboarding, digital payment recording, and affiliate store bridging:

  • B2C Storefront: Responsive desktop/mobile shopping interface with live search, category pills, brand filters, price/rating sorting, wishlist persistence, 3-item side-by-side comparison, and 12% Dosti Group Deals.
  • Multi-Vendor Seller Marketplace: Dedicated /seller portal enabling verified Indian sellers to list, pause, or delete products with instant daily ₹20/item fee calculation and UPI QR settlement.
  • Partner Store & Affiliate Bridge: Links products to official partner websites (external_url), logs click redirects, imports cooperating Shopify store feeds (/api/catalog/sync-shopify), and records external store receipts.
  • Out of Scope: Automated silent purchasing inside third-party platforms (such as Amazon or Flipkart) without buyer 2FA/payment authorization, and physical courier fleet management.

5. Major Modules of the System

  1. User Authentication & Profile Module: Handles registration and login (Login.jsx, Register.jsx) with bcryptjs password hashing and persistent local session context.
  2. Catalog & Interactive Widgets Module: Serves paginated, filtered, and sorted items from PostgreSQL (/api/products, /api/categories, /api/brands). Renders multi-image gallery switcher, No-Cost EMI calculator (3/6/12 months), 5% UPI cashback preview, and 5★–1★ review breakdown bars inside ProductDetailModal.jsx.
  3. Cart, Wishlist & Dosti Group Deal Module: Supports standard cart items alongside 12% discounted group-buy deals (DostiDealModal.jsx) and 3-product spec comparison (CompareModal.jsx).
  4. Phone OTP & NPCI UPI Verification Module: Generates cryptographically random 6-digit OTPs stored as SHA-256 hashes in phone_otps (5-minute TTL, 5-attempt cap), validates 30+ NPCI VPA bank handles, generates live UPI deep-link QR codes, and captures UTR transaction references (UpiPaymentModal.jsx).
  5. Seller Marketplace & Fee Ledger Module: Onboards OTP-verified sellers, inserts seller items into products (source = 'seller'), calculates active-item daily billing at ₹20/item/day, and records Admin UPI settlements in seller_fee_ledger.
  6. Partner Website Bridge & Order/Invoice Module: Logs outbound store redirects (/api/bridge/redirect), dispatches partner webhooks on order placement, imports external partner receipts (/api/orders/sync-external), and generates printable Tax Invoices with QR warranty seals (InvoiceModal.jsx).

6. Working Process

6.1 Buyer Shopping, UPI Checkout & Store Bridge Workflow

  1. Discovery: User visits ShopEase, filters by 14 categories or searches by brand/keyword. Backend queries Supabase PostgreSQL and returns paginated real products.
  2. Inspection: Clicking any product opens ProductDetailModal showing multi-angle gallery thumbnails, seller hub/GSTIN, EMI options, review distribution, and pincode ETA.
  3. Checkout Choice:
    • Path A (Native ShopEase UPI Checkout): User adds items to cart or clicks Buy with UPI. For first-time UPI linking, user enters a valid NPCI VPA and authenticates their mobile number via 6-digit Phone OTP. Upon UPI/QR UTR confirmation, POST /api/orders saves the order, checks if the seller has a store_webhook_url (forwarding the order if present), and displays a printable Tax Invoice.
    • Path B (Original Partner Website Bridge): User clicks Visit Original Store Website. ShopEase logs the redirect in external_redirects and opens the merchant’s product URL. After completing checkout on that website, the user can save their Partner Order ID and receipt inside /orders via Sync External Store Receipt.

6.2 Seller Onboarding & ₹20/Item/Day Billing Workflow

  1. Seller opens /seller, enters store/owner/GSTIN/hub/UPI details, and triggers Send OTP (POST /api/otp/send).
  2. Upon 6-digit OTP verification (POST /api/otp/verify), seller account is activated in sellers.
  3. Seller publishes real products with verified photo URLs; items immediately appear in the live ShopEase catalog.
  4. System calculates daily fee (Active Items × ₹20). Seller scans the Admin Platform UPI QR code and submits the UTR transaction ID, updating seller_fee_ledger and platform revenue analytics.

9. Advantages

  • Zero-Maintenance Cloud Scaling: Serverless execution on Vercel and Cloudflare removes idle VPS costs while scaling cleanly with traffic spikes.
  • Authentic Visual Integrity: Automated HTTP HEAD validation during seeding guarantees that every single one of the 429 products displays a valid, unique product photograph.
  • Dual Revenue Streams: Combines recurring daily marketplace SaaS revenue (₹20/item/day from local sellers) with zero-inventory affiliate commissions from external stores.
  • Real Indian Payment Ergonomics: Validates 30+ real NPCI UPI handles, generates scannable QR codes, tracks UTR references, and produces printable GST invoices.
  • Multi-Runtime Portability: Identical business logic runs cleanly on both Express/Vercel and dependency-light Cloudflare Workers.

10. Limitations and Challenges

  • Third-Party Checkout Boundary: External platforms such as Amazon India and Flipkart prohibit automated silent cart/order placement via external servers due to buyer login, RBI 2FA, and anti-bot protections. External purchases must be completed on the partner website and optionally synced back via Order ID.
  • PA-API Eligibility Threshold: Amazon India requires initial qualifying affiliate sales (typically 3–10 orders in 30 days) before unlocking live PA-API / Creators API credentials.
  • SMS OTP Gateway Regulation: In production India telecom networks, sending live SMS OTPs via Fast2SMS or Twilio requires TRAI DLT entity/template approval; until configured via environment variables, the app operates in a safe Sandbox OTP mode.
  • Serverless Connection Churn: Serverless functions open short-lived connections to PostgreSQL, mitigated via Supabase’s Transaction Pooler (port 6543).

11. Security and Privacy

  • Password Hashing: User credentials are salted and hashed with bcryptjs (cost factor 10) before database storage; plaintext passwords are never persisted.
  • Cryptographic Phone OTP: 6-digit OTPs are generated via crypto.randomInt, hashed using SHA-256 tied to phone and purpose, automatically expire after 5 minutes, and lock after 5 failed verification attempts.
  • Parameterized SQL Queries: Every PostgreSQL statement uses positional parameters ($1, $2, ...) to prevent SQL injection attacks.
  • UPI VPA Verification: Strict client + server regex and NPCI handle allowlist prevent malformed or spoofed payment addresses.
  • Secret Isolation: Sensitive API tokens (SMS gateways, Amazon Partner Tag / Creators API keys) are designed exclusively for Vercel/Cloudflare Environment Variables rather than client bundles.
